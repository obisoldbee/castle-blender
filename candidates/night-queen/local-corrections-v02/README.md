# Night Queen: local corrections v02 — UNAPPROVED CANDIDATE

This is an independent candidate, not the official castle scene and not a completed reconstruction. It consolidates only verified local corrections from the existing candidate:

- Feet: seam18 repair integrated into the complete figure (integrated19). The ankle line was an overlapping cut-body boundary, not a decorative fold. Lower calves were stitched into the body; lower-leg boundary test reports zero nonmanifold edges. Thick articulated toes retained.
- Wings: wings20 pulls the supporting backing inside feather endpoints, removing the protruding lower lip and dark groove. No new covert patches adopted.
- Symbols ONLY: hands21 closes unintended open ring spline seams; photo-right ring/rod receive a modest oval/curved-rod correction. This does NOT correct the hand mesh or grasp. Damaged opposite-side source details were not mirrored as newly reconstructed facts.
