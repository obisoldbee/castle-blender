# 屋顶比例整改

用户于 2026-11-08 认可将锥屋顶高度缩至 65% 的同机位试作。本次将该方向写回生成脚本，而不是只修改图片或留一份变形副本。

## 范围

15 个主要塔屋顶保持檐口直径、塔身和位置，高度乘 0.65。主塔由高约 8.008、直径 4.66，调整为高约 5.205、直径仍为 4.66；高径比从约 1.72 降为 1.12（均为场景单位）。20 个屋面窗的小锥顶也采用相同比例。

屋面窗重新按缩短后的屋面高度定位，窗体、玻璃和小屋顶整体跟随新挂点；不是只缩主锥而把小窗留在原处。塔顶杆件和球饰跟随新顶点，保留自身尺寸。石质尖顶球饰一组不在此轮修改范围。

这是一项用户认可的视觉比例选择，不是特定年代、建筑或排水标准的历史复原。原始包中缺少代码曾引用的 proportions.md 和最初参考图，不能补造出处。

## 保留

滴水兽函数未改；另行进行的滴水兽研究/试作未经确认不并入本提交。动画脚本、已认可的夜景和黄昏灯光/曝光参数未改；环绕相机也不改。屋顶几何变化可以自然改变阴影，但不通过重调照明掩盖变化。

## 验证

两份完整工程均已从修改后的源代码重新生成，Blender 4.3.2 打开及结构检查通过。两份工程各有 15 个主屋顶、20 组屋面窗；高度、檐口直径、杆球位置和窗体穿入锥面的几何检查通过。9 项 Python 单元测试通过。

帧 1 与 721 的循环海面几何 RMS 为 0，相机、月亮及曝光首尾闭合。帧 1、110、245、385、560、720 的灯光、曝光、相机参数快照与前一版完全一致。验收 JSON 位于 [validation/roof](validation/roof/)，构建指纹位于 [build.json](validation/build.json)。

已检查帧 1、245、385、560、720 的低清诊断渲染及独立屋顶近景。近景可见小窗已重新贴合缩短后的屋面。诊断图使用临时降低的海面网格、8 或 24 样本、无降噪，因此有明显噪点；未把诊断设置保存回交付工程。完整 720 帧高质量渲染未执行，高网格海面在当前内存条件下仍有既知风险。
